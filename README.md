## SafeCity-Criminal-Intelligence

## Project Description
 The SafeCity is a web-based application designed to improve public awareness and promote personal safety. It provides users with information about common crimes, safety precautions, latest crime alerts, and risk analysis to help create a safer community.

## Objectives
- To spread awareness about different types of crimes.
- To provide safety tips for preventing criminal activities.
- To display recent public safety alerts.
- To encourage citizens to take responsibility for creating a safer society.

## Features / Modules
- **Common Crimes:** Provides information about different types of crimes, causes, and prevention methods.
- **Weekly Safety Tips:** Shares safety recommendations related to online security, personal protection, and crime prevention.
- **Latest Alerts:** Displays recent public safety and crime-related alerts.
- **Citizen Safety Pledge:** Encourages users to contribute towards building a safer society.
- **Risk Analysis:** Helps users understand potential safety risks.
